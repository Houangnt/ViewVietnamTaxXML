1. Issue
- Ticket + specs update liên tục
- Relationship extraction accuracy

- GraphRAG dựa AI nên có thể miss relationships
   + Cần manual validation lần đầu
   + Thêm explicit metadata (JIRA custom fields) để đánh dấu spec linkage

2. Temporal Context Graphs (Thiết kế cho data thay đổi)
- Tickets + specs luôn thay đổi: Ticket được update, spec được modify
- Graphiti lưu validity windows cho mỗi fact:
  + "Ticket PROJ-123 affects Spec-v2" (valid from 2024-01-15 to 2024-03-20)
  + "Ticket PROJ-123 affects Spec-v3" (valid from 2024-03-20 onwards)
3. Hybrid Retrieval (semantic + keyword + graph traversal)
- Không chỉ semantic search, còn có graph traversal
  + Dev query "Ticket PROJ-456" → tự động thấy toàn bộ specs affected
4. Incremental updates (không cần rebuild toàn bộ graph)
- Ticket mới tạo? → Thêm vào graph ngay lập tức
- Spec update? → Update facts, old facts marked as invalid (not deleted)
